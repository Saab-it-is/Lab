# Hello World Examples

A collection of "Hello World" programs in different programming languages.

## Purpose

This example demonstrates the basic syntax of various programming languages through the simplest possible program.

## Languages Included

- Python
- JavaScript
- Shell

## Running the Examples

### Python
```bash
python3 hello.py
```

### JavaScript
```bash
node hello.js
```

### Shell
```bash
bash hello.sh
```

## Learning Points

- Basic syntax differences between languages
- How to run programs in different environments
- Standard output operations
