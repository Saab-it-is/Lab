# Examples

This directory contains tutorial-style code examples demonstrating specific concepts or technologies.

## Structure

Each example should be:
- Self-contained and easy to run
- Well-commented and educational
- Focused on teaching a specific concept

## Example Structure

```
examples/
├── python-basics/
│   ├── README.md
│   ├── hello_world.py
│   └── variables.py
├── javascript-async/
│   ├── README.md
│   ├── promises.js
│   └── async-await.js
```
